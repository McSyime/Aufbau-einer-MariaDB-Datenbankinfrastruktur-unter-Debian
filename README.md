# Aufbau einer MariaDB Datenbankinfrastruktur unter Debian
Eine Infrastruktur einrichten, bestehend aus:  einer virtuellen Debian-Maschine; einem MariaDB-Server; einer phpMyAdmin-Verwaltungsoberfläche; einer kleinen Demo-Datenbank; mehreren Benutzern mit unterschiedlichen Berechtigungen; einer Strategie für Backups und Wiederherstellungen; technischen Tests.
